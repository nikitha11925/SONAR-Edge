4. Feature Extraction: Formulas, Script and CSV Files

Formulas

For each 1024-sample window (64 ms), moved by 512 samples (32 ms):

1. Hann window:   w[n] = 0.5 − 0.5·cos(2πn / 1024),   n = 0 … 1023
2. FFT and power:   P[k] = | Σn x[n]·w[n]·e−j2πkn/1024 |² ,   k = 0 … 512   (power = 2)
3. Mel bands:   M[b] = Σk Hb[k]·P[k],   b = 1 … 64   (H = librosa's triangular mel filters)
4. Log:   L[b] = (20 / power)·log10(M[b] + ε) = 10·log10(M[b] + ε),   ε = 2.22 × 10−16

A 10 s clip at 16 kHz gives 313 frames × 64 bands. These settings are copied from Hitachi's MIMII baseline so the results can be compared.

def load_channel0(path):

def logmel(y, n_mels=N_MELS):
    mel = librosa.feature.melspectrogram(y=y, sr=16000, n_fft=N_FFT, hop_length=HOP,
                                         n_mels=n_mels, power=POWER)
    return (20.0 / POWER * np.log10(mel + sys.float_info.epsilon)).astype(np.float32)

5. The Model: Script and Saved Model Files

A fully connected (dense) autoencoder: it compresses the 64 input values into a small bottleneck and rebuilds them. It's trained on healthy sound only, so unusual (faulty) sound is rebuilt badly.

acoustic\model_selection.py: build() 
def build(in_dim, depth, hidden, bott):
    if depth == 'deep':
        sizes = [in_dim, hidden, hidden, bott, hidden, hidden, in_dim]     # fan: 64-32-32-8-32-32-64
    elif depth == 'shallow':
        sizes = [in_dim, 32, bott, 32, in_dim]                          # slider, valve
    else:
        sizes = [in_dim, 16, bott, 16, in_dim]                          # pump ('tiny')
    layers = []
    for i in range(len(sizes) - 1):
        lin = nn.Linear(sizes[i], sizes[i + 1])
        nn.init.xavier_uniform_(lin.weight)
        nn.init.zeros_(lin.bias)
        layers.append(lin)
        if i < len(sizes) - 2:
            layers.append(nn.ReLU())                                       # ReLU on hidden layers, linear output
    return nn.Sequential(*layers)

6. Training

acoustic\model_selection.py: train() 
def train(model, X, epochs, seed, batch=512):
    torch.manual_seed(seed)
    rng = np.random.default_rng(seed)
    n_val = int(0.1 * len(X))
    Xtr = torch.from_numpy(X[:len(X) - n_val])
    opt = torch.optim.Adam(model.parameters(), lr=1e-3)
    loss_fn = nn.MSELoss()
    for _ in range(epochs):
        model.train()
        perm = torch.from_numpy(rng.permutation(len(Xtr)))
        for i in range(0, len(Xtr), batch):
            xb = Xtr[perm[i:i + batch]]
            opt.zero_grad()
            loss_fn(model(xb), xb).backward()        # input = target (autoencoder)
            opt.step()
    return model

7. Scoring and Two-Stage Calibration

Formulas

Standardise (calibration step 1):   zb = (Lb − μb) / (σb + 10−6),   μ, σ from the new machine's first 30 healthy clips
Frame error:   e = (1/64)·Σb (ẑb − zb)²     Clip score:   s = mean of e over all frames of the 10 s clip
Alert level (calibration step 2):   τ = mean(s) + 3·std(s) over the next 30 healthy clips   →  RED if s > τ
acoustic\model_selection.py: stats(), file_scores(), tau() 
def stats(vecs):
    X = vecs.reshape(-1, vecs.shape[-1])
    return X.mean(0), X.std(0) + 1e-6                       # per-band mean and spread

def file_scores(model, vecs, mu, sd, chunk=32):
    model.eval()
    out = []
    with torch.no_grad():
        for i in range(0, len(vecs), chunk):
            v = vecs[i:i + chunk]
            nf, nv, d = v.shape
            x = torch.from_numpy(((v - mu) / sd).astype(np.float32)).reshape(-1, d)
            out.extend(((model(x) - x) ** 2).mean(1).reshape(nf, nv).mean(1).tolist())
    return np.array(out)                                        # one score per clip

def tau(s):
    return float(s.mean() + 3 * s.std())                         # alert level

8. Evaluation Protocol, Metrics and Results

Protocol (leave-one-machine-out)

  • For each machine type and noise level, each of the 4 machines is the "new machine" in turn. The model trains on the other 3.
  • Test set of the new machine: Hitachi's split, N healthy clips + all N faulty clips (balanced).
  • Calibration uses the remaining healthy clips: 30 for the standardisation and the next 30 for the alert level. Calibration and test clips never overlap.
  • 4 types × 3 noise levels × 4 machines × 3 seeds = 144 runs. Machine 06 was never used to choose a design.

Metric formulas

Positive class = faulty. Decision: clip score > alert level → alert.

Device says GREENDevice says RED
Actually healthyTN (correct)FP (false alarm)
Actually faultyFN (missed fault)TP (fault caught)
acoustic\evaluation_lib.py: full_metrics() 
def full_metrics(sn, sa, alert):
    y = np.r_[np.zeros(len(sn)), np.ones(len(sa))]
    s = np.r_[sn, sa]
    tp = int((sa > alert).sum());  fn = len(sa) - tp
    fp = int((sn > alert).sum());  tn = len(sn) - fp
    recall = tp / (tp + fn)
    spec = tn / (tn + fp)
    prec = tp / (tp + fp)
    f1 = 2 * prec * recall / (prec + recall)
    return dict(auc=roc_auc_score(y, s), precision=prec, recall=recall, f1=f1,
                accuracy=(tp + tn) / (tp + tn + fp + fn), fpr=fp / (fp + tn),
                specificity=spec, balanced_accuracy=(recall + spec) / 2, tp=tp, fp=fp, tn=tn, fn=fn)

def precision_at_prevalence(recall, fpr, p):                    # precision if only a share p is faulty
    return recall * p / (recall * p + fpr * (1 - p))
Recall = TP/(TP+FN) · Precision = TP/(TP+FP) · False-alarm rate = FP/(FP+TN) · F1 = 2PR/(P+R) · AUC = P(scorefaulty > scorehealthy)

firmware\common\ae_pipeline.c: ae_logmel() 
void ae_logmel(const int16_t pcm[N_FFT], float out[N_MELS])
{
    for (int i = 0; i < N_FFT; i++) { s_re[i] = (pcm[i] * (1.0f / 32768.0f)) * HANN[i]; s_im[i] = 0.0f; }
    fft1024();                                                         # radix-2 FFT, 1024 points
    for (int k = 0; k < N_BINS; k++) s_re[k] = s_re[k] * s_re[k] + s_im[k] * s_im[k];   # power
    const float *w = MEL_W;
    for (int m = 0; m < N_MELS; m++) {
        float acc = 0.0f;
        for (int j = 0; j < MEL_COUNT[m]; j++) acc += w[j] * s_re[MEL_FIRST[m] + j];
        w += MEL_COUNT[m];
        out[m] = 10.0f * log10f(acc + 2.220446e-16f);                 # same formula as Python
    }
}

13. Known Limitations (Reported, Not Hidden)

  • Valves are not detected (AUC about 0.5). Their faults are short clicks that get averaged out over a 10 s clip.
  • The fixed alert rule (mean + 3·std) is too strict for pumps (35% false alarms) and too lenient for fans and sliders (66% and 73% of faults caught). Median + 3·MAD is being tested as a more robust rule.
  • Heavy noise (−6 dB) lowers accuracy, and calibrating at a different noise level than the machine runs at raises false alarms (8% → 44% for fans).
  • Own-fan test: one machine, a phone microphone and few clips. It's a first check, not proof.
  • On the board, sound currently comes from recorded clips over USB until the INMP441 microphone is connected. Sound–vibration fusion and the energy and noise estimate are still planned.
